# Состав публичного релиза

Это новая чистая история Git, собранная из текущих рабочих исходников, включая последние изменения сканера и Core. История исходного репозитория не переносилась.

Оставлены исходники сервисов, миграции, npm lockfiles, тесты, рабочая документация разметки и точный C4 runtime source. Исключены промежуточные версии экспериментов, отчёты оценок, служебные агентские файлы, сборки, окружения, node_modules, логи, DB dumps и крупные артефакты. Реальные каталоги, OCR snapshots, эталоны и тестовые наборы передаются отдельно. Встроенная mock-консоль содержит только синтетические примеры.

Основной Compose запускает PostgreSQL, API, настоящий Core и Web. Профиль `annotation` включает сервис разметки, миграции и вспомогательные модели; профиль `llm` — внешний LLM-контроллер. Старые README сервисов и `legacy-development.md` описывают исторический dev workflow; актуальная точка входа — корневой README.

Публикация кода не означает публикацию датасета, весов или предоставление новой лицензии на сторонние материалы. Публичная видимость репозитория сама по себе не является open-source лицензией.

## Проверено при подготовке

- SHA-256 всех 10 539 файлов отдельно поставленного Core runtime и точные байты C4 в Git.
- Docker production build Web и API; TypeScript build/typecheck Recognize.
- 85 frontend-тестов: recognition 9, references 7, scanner 20, workflow 49.
- API: 31 тест пройден, 5 DB integration tests пропущены без отдельной тестовой конфигурации.
- Восстановление снимка в отдельную пустую PostgreSQL БД.
- Один сквозной запрос через новую Web/API-сборку и восстановленную БД: правильный slug и карточка, около 4,2 секунды. Использован уже работающий frozen Core; второй GPU-инстанс не запускался.

Пересборка Core из pip lockfile, полный профиль LLM/разметки и работа на другой GPU-машине в этой проверке не выполнялись.
